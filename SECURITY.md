# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately using [GitHub private vulnerability reporting](https://github.com/TeamEasyDCIM/custom_remote_module/security/advisories/new) or by e-mail to konradbi@easydcim.com.

Please include a description of the issue, steps to reproduce it and the affected module version. We will acknowledge your report and keep you informed about the fix.
